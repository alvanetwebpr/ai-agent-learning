Phase 01 · Input
OBSERVE — Environment → Perception Neurons

Every learning cycle begins with observation. The agent looks at the world — or more precisely, it receives a structured representation of the world called the state.

In the animation, a cyan pulse travels from the Environment box into the Perception Neurons. This represents the state being fed into the network. The neurons light up as they receive this data.

Key Insight
Designing a good state representation is one of the most important — and most underestimated — decisions in building an AI agent. If your state does not include the right information, the agent cannot learn the right behaviour, no matter how powerful the network.

In practice, this input might be pixels from a camera, sensor readings from a device, text tokens from a user message, or structured data from a database. Whatever the agent can observe, it enters here.

Phase 02 · Computation
PROCESS — Forward Pass Through Policy Network

Once the state enters the network, it flows forward through all three layers in what we call a forward pass. Each neuron receives weighted inputs from the previous layer, applies its activation function, and passes the result forward.

The neurons light up sequentially — Perception, then Hidden, then Action. The connection lines between them glow as data flows through. This entire process happens in milliseconds in a real system.

What is ReLU?
ReLU (Rectified Linear Unit) is the activation function: f(x) = max(0, x). It introduces non-linearity, allowing the network to learn complex patterns. Without it, the entire network would collapse into a single linear transformation — incapable of learning anything interesting.

The output of this forward pass is a set of Q-values — one number per possible action. The agent is essentially asking itself: "Given what I see right now, which action do I believe will lead to the best outcome?"

f(x) = max(0, Wx + b)  ·  ReLU Activation

Phase 03 · Decision
ACT — Action Neurons → Environment

The agent now acts. It selects the action with the highest Q-value and executes it in the environment.

ε-Greedy Exploration
Early in training, the agent does not always pick the best-known action. It uses ε-greedy exploration — where ε (epsilon) is a probability of choosing a random action instead of the best-known one. This is intentional: if the agent always exploits what it knows, it will never discover better strategies.

As training progresses, epsilon decreases. The agent explores less and exploits more, because it has built up enough knowledge to make reliable decisions.

Analogy: Think of a new employee who always does things the way they were taught on day one. They will never discover a more efficient process unless they occasionally try something different. Exploration is how agents — and people — grow.

action = argmax(Q(s,a))  with prob. (1-ε)  ·  ε-Greedy

Phase 04 · Feedback
REWARD — Environment Returns the Reward Signal

After acting, the environment responds with a reward — a numerical score that tells the agent how good or bad its action was.

The reward signal is the most powerful — and most dangerous — component of the entire system. It is powerful because it is the only feedback the agent receives. It is dangerous because agents are extraordinarily good at optimising exactly what you measure, even if that is not what you actually want.

Goodhart's Law in AI
"When a measure becomes a target, it ceases to be a good measure." If you reward a customer service agent purely on call resolution speed, it will learn to hang up on customers quickly. If you reward it on satisfaction scores, it will learn to actually solve problems. The reward function is your policy.

Designing a good reward function is arguably the most important skill in building a good AI agent.

Phase 05 · Memory
STORE — Experience → Memory / Replay Buffer

After each action-reward cycle, the agent stores the entire experience as a tuple:

(state, action, reward, next_state)  →  Replay Buffer

The Replay Buffer serves two critical purposes. First, it allows the agent to learn from past experiences rather than only the most recent one. Second, it breaks the correlation between consecutive training samples — a problem that would otherwise cause the network to overfit to recent events and forget earlier learning.

Why Randomness Matters
Without a replay buffer, an agent trained on a sequence of similar states would essentially "forget" how to handle states it has not seen recently. The buffer ensures diversity in training data, which is essential for generalisation. Random sampling from the buffer is not an accident — it is a deliberate design choice.

Phase 06 · Backpropagation
LEARN — Sample Replay Buffer → Backpropagation

This is where the actual learning happens. A random mini-batch of experiences is sampled from the Replay Buffer. For each experience, the agent computes the Temporal Difference (TD) error using the Bellman equation:

TD Error = r + γ · max(Q(s',a')) − Q(s,a)

Where r is the reward received, γ (gamma) is the discount factor, Q(s',a') is the estimated Q-value of the best action in the next state, and Q(s,a) is the current Q-value estimate.

The Bellman Equation
The TD error measures how wrong the agent's prediction was. This error is then propagated backward through the network — adjusting the weights of every connection to reduce the error. This is backpropagation: the engine of all neural network learning.

⚡
Phase 07 · Optimisation
UPDATE — Weights Refined via Gradient Descent

The weight update is performed by an optimizer — typically Adam (Adaptive Moment Estimation) in modern AI systems. The update rule is:

W ← W − η · ∇Q   (Adam Optimizer)

Where W is the current weight, η (eta) is the learning rate — how large a step to take — and ∇Q is the gradient — the direction of steepest error.

Synaptic Plasticity
Think of this as the digital equivalent of synaptic plasticity — the biological principle that neurons that fire together, wire together. Connections that led to good outcomes are strengthened; those that led to poor outcomes are weakened. The learning rate is one of the most sensitive hyperparameters: too high and the agent overshoots; too low and training takes forever.

✅
Phase 08 · Convergence
CONVERGE — Agent Improves Over Episodes

After enough episodes, the agent converges — its Q-values stabilise, its loss decreases, and its behaviour becomes consistently good.

The Q-value curve rises as the agent learns to earn more reward. The loss curve falls as the agent's predictions become more accurate. These two curves moving in opposite directions are the signature of a healthy, learning agent.

The Loop Never Ends
The best AI agents are not deployed and forgotten. They are continuously monitored, retrained, and refined — just like the animation loops, episode after episode, always improving. Convergence is not a destination; it is a moving target as the environment and requirements evolve.

Watch the agent's movement in the environment become tighter and more deliberate over episodes — less random exploration, more confident exploitation of learned strategies.

Core Principles

The Three Pillars of a Good AI Agent

The quality of your agent depends on three foundational pillars. Neglect any one of them and the entire system suffers.

01
⚡
Reward Function Design
Your reward function is your agent's constitution. It defines what "good" means. If it is misaligned with your actual goals, the agent will optimise for the wrong thing — perfectly, efficiently, and at scale. Invest serious time in reward engineering before writing a single line of network code.
Reward hacking, misaligned behaviour
02
💾
Memory Architecture
An agent without memory is an agent that cannot learn from experience. The Replay Buffer is the minimum viable memory. More advanced agents use episodic memory, working memory, and long-term knowledge stores — architectures that mirror human cognitive systems.
Forgetting, poor generalisation
03
🧠
Policy Network Architecture
The network is the agent's reasoning engine. Its depth, width, and activation functions determine the complexity of patterns it can learn. For language-based agents, this is a Transformer. For vision-based agents, a CNN. Matching the architecture to the task is essential.
Underfitting, incapacity for complex tasks
